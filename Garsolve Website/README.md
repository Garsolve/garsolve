# Garsolve Website

Production-ready static site for GitHub Pages.

## Deploy

Upload the contents of this folder to the repository root, then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**.

## Structure

- `index.html` — single-page Garsolve website
- `css/` — design system and responsive styling
- `js/` — navigation, floating particles, scroll reveal, and site behavior
- `assets/logo/` — Garsolve branding
- `assets/icons/` — Power Platform icon
- `assets/images/` — social preview image
- `robots.txt` / `sitemap.xml` — search-engine files
- `.nojekyll` — GitHub Pages compatibility
